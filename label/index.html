① 导入柜号 & SKU

点击选择 / 拖入 / Ctrl+V 粘贴截图，自动文字识别(OCR)
识别规则

• 柜号：4 个字母 + 7 位数字（如 MRSU4879830），校验位不对会提示。
• SKU：同一行里 ≥5 位、含字母的编码；行内若跟着数字，当作该 SKU 的数量（打在 NO 后面，如 /75）。
• 能识别表头"SKU / 数量 / QTY / 柜号"等，表头行自动跳过。
• 截图识别后请在右边表格核对一下（O/0、I/1 容易混）。

标签尺寸 / 打印机设置（320 标签机）

浏览器网页无法在代码里指定打印机。想做到"点确认直接从 320 打出来、不弹窗"：
1. Windows「设置 → 打印机」里把 320 标签机设为默认打印机（并关闭"让 Windows 管理默认打印机"）；在打印机首选项里把纸张设成与上面相同的尺寸。
2. 给 Chrome / Edge 建一个专用快捷方式，目标末尾加 --kiosk-printing，例如：
"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing https://roamoid.github.io/label/
（先关掉所有 Chrome 窗口再用这个快捷方式打开）此后点「确认打印」会直接发到默认打印机。
不加该参数也能用：弹出打印窗口时选一次 320，Chrome 会记住上次的打印机，边距选"无"，缩放 100%。
