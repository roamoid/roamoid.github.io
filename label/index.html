备用：用截图识别
点击选择 / 拖入 / Ctrl+V 粘贴截图（自动文字识别）
识别规则

• 柜号：4 个字母 + 7 位数字（如 MRSU4879830），校验位不对会提示。
• 整页复制时，只读取「SKU … CTNS/PCS/数量」表头以下的行。
• SKU：行内 ≥5 位、含字母的编码；其后的数字当作数量（打在 NO 后面，如 /75）。
• 截图识别后请核对一下（O/0、I/1 容易混）。

标签设置

标签尺寸 / 打印机（320 标签机）

网页无法在代码里指定打印机。想点「打印」直接从 320 出纸、不弹窗：
1. Windows「设置 → 打印机」把 320 标签机设为默认打印机（关闭「让 Windows 管理默认打印机」），打印机首选项里把纸张设成与上面相同的尺寸。
2. 给 Chrome / Edge 建专用快捷方式，目标末尾加 --kiosk-printing，例如：
"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing https://roamoid.github.io/label/
（先关掉所有 Chrome 窗口再用它打开）。不加也能用：弹出打印窗口时选一次 320，边距选「无」，缩放 100%。
